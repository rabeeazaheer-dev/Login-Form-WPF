# Login Form - WPF Application 🔐

A modern, clean WPF Login Form UI built using C# .NET and WPF.

## ✨ Key Features
* **Clean UI:** Modern desktop layout.
* **Responsive Controls:** Custom text fields and buttons.

## 🛠️ Tech Stack & Tools
* **Language:** C#
* **Framework:** .NET Framework / WPF
* **IDE:** Visual Studio

## 🚀 How to Run
1. Open `WpfApp1.sln` in Visual Studio.
2. Press `F5` to build and run the application.
